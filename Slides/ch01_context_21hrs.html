Context rot

창 안의 토큰 수가 늘어날수록,
모델이 그 안의 정보를 정확하게 회상하는 능력이 떨어지는 현상

Anthropic (2025) · Hong et al. (2025)

  • 출처: 정의 Anthropic (2025). 실험 Hong, Troynikov, Huber (2025), “Context Rot: How Increasing Input Tokens Impacts LLM Performance”, Chroma. LongMemEval 과제, 두 막대는 같은 축척.
  • 같은 질문에 필요한 부분만 준 입력(약 300 토큰)과 전체 기록(약 113K 토큰)을 비교. 실험한 모든 모델에서 짧은 입력의 성능이 뚜렷하게 높았다.
  • 방해 문장 하나만 추가되어도 성능이 기준선보다 낮아졌다.
  • 대상: GPT-4.1, Claude 4, Gemini 2.5, Qwen3 등 18개 모델. 정확한 수치는 원문 그래프 인용.
컨텍스트 엔지니어링

Context engineering

추론 중 모델에 들어가는 최적의 토큰 집합을 선별하고 유지하는 전략

Write

창 밖, 파일에 기록한다

Select

필요한 것만 창으로 불러온다

Compress

창 안의 기록을 줄인다

Isolate

작업을 별도의 창으로 나눈다

Anthropic (2025) · Martin (2025)

  • 출처: 정의 Anthropic (2025). 네 가지 분류 Lance Martin, “Context Engineering for Agents” (LangChain, 2025).
  • Write → CLAUDE.md, MEMORY.md, plan 파일. compaction 뒤에도 파일은 다시 적재된다.
  • Select → @파일, 검색 도구, skills(설명만 먼저, 본문은 호출 시).
  • Compress → /compact, auto-compact, /clear.
  • Isolate → subagents(별도 창에서 탐색, 요약만 반환), hooks.
