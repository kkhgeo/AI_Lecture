출처: 창 정의 Claude Docs Glossary. 한계와 부패 정의 Claude Docs "Context windows". 그래프 Hong, Troynikov, Huber (2025) "Context Rot", Chroma (색만 다크로 치환). 창은 학습 데이터와 다르다. 최신 모델 다수는 1M, 그 외 200K. 입력과 출력의 합이 이 한도를 넘을 수 없다. 입력만으로 넘으면 요청 오류, 생성 중 닿으면 출력이 멈춘다. 그래프 읽기: 같은 질문에 필요한 부분만 준 입력(Focused, 구리색, 약 300 토큰)과 대화 기록 전체(Full, 회색, 약 113K 토큰). 예: Claude Opus 4는 0.92 vs 0.38. 모든 모델에서 Full이 낮다. 핵심: 한도 안이라도 많이 채울수록 흐려진다 → 다음 장(Context engineering).
