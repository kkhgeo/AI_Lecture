# 슬라이드 디자인 원칙 (최종)

기준 슬라이드: `lecture_context_v4.pptx` 1번 "컨텍스트(Context)" (2026-09-29 확정).
새 슬라이드는 이 슬라이드의 값·배치·표현 방식을 그대로 따른다. 벗어나야 하면 먼저 묻는다.

## 1. 캔버스와 배경
- 16:9, 1920×1080px (PPTX 960×540pt, 1px = 0.5pt).
- 배경 검정 `#000000`. 로고·모서리 선·페이지 번호·진행 막대·상자·버튼·카드 없음.

## 2. 글자 (Paperlogy만 사용)
| 요소 | PPTX | HTML | 굵기 | 색 | 위치 |
|---|---|---|---|---|---|
| 제목 | 36pt | 72px | ExtraBold(8) | `#D9D9D9` | x200, y96 |
| 정의 | 20pt | 40px | Regular(4) | `#FFF3EA` | x200, y212, 한 줄, 전체 폭 |
| 보조 문장 | 15pt | 30px | Regular(4) | `#8C8681` | 왼쪽 칸 x200, y330부터, 폭 약 500px, 덩어리 간격 28px |
| 캡션 | 12pt (최소) | 24px | Regular(4) | `#8C8681` | 그림 바로 아래, 오른쪽 정렬 |
- 이 네 크기 밖의 글자는 만들지 않는다. 캡션 12pt가 최소 크기다.
- 강조는 굵기나 색 대신 위치와 크기(제목 → 정의 → 보조)로만 한다. 보조 문장 안에서 굵게 쓰지 않는다.

## 3. 표현 방식
- 제목: `용어(English)` 예) 컨텍스트(Context)
- 정의: `용어: 정의.` 한 문장. 제목에 영어가 있으므로 정의에는 한글 용어만.
- 보조 문장: 정의를 부연하는 짧은 문장 2~4덩어리. 순서는 포함 범위 → 구성 → 아닌 것 → 참고.
- 곁가지 개념은 `※ 용어(English): 짧은 정의 (핵심 수치)` 한 덩어리로.
- 캡션: 그림이 보여 주는 것을 개조식으로(명사형 종결, 마침표 없음). 예) 턴마다 입력·출력 누적, 컨텍스트 증가
- 카피·슬로건 금지. 정의와 수치는 원문을 확인한 뒤 옮긴다.
- 화면에 출처를 쓰지 않는다. 출처·세부 수치·시연 안내는 발표자 노트에.

## 4. 배치
- 여백: 왼쪽 200px, 오른쪽 100px.
- 위: 제목 → 정의(전체 폭). 아래: 왼쪽 보조 문장 칸 + 오른쪽 큰 그림(폭 1000~1100px) + 캡션.
- 한 장에 그림은 하나.
- 예외: 가로로 아주 긴 그림(가로:세로 약 2.5 이상, 칸이 여러 개)은 전체 폭으로 두고, 보조 문장을 각 칸 아래에 칸 폭에 맞춰 둔다. (4번 "네 가지 전략")

## 5. 그림
- 원문 그림을 우선 쓰고 색만 가공한다(원본은 `assets/source/`, 가공 내역은 `assets/source/SOURCES.md`). 원본 이미지로 글자를 키울 수 없으면 같은 수치로 다시 그리되, 원본의 형식(그래프 종류·제목·축 이름·항목 이름·범례·테두리)은 그대로 따르고 색과 글자 크기만 바꾼다.
- 그림 속 용어는 영어. 그림 속 글자는 칸 안에서 가능한 만큼 키운다.
- 그림 색: 입력·골라 넣은 것 = 구리 `#E4B592`, 쌓인 기록·전체 = 회색 `#7E7E7E`, 밝은 칸 안 글자 = 검정, 배경 검정, 선·라벨 = 크림 계열.
- 파일: `assets/fig-*.svg`(HTML) + 같은 이름 `.png`(PPTX용).

## 6. 제작과 PPTX 변환
- 원본은 `lecture_context.html`. `node bake.mjs` → `python make_pptx.py <출력파일>`. 미리보기 `previews/`.
- 편집 가능 텍스트는 `data-tx`, 그림은 `data-img`.
- 움직이는 그림(SVG 애니메이션)은 `node tools/svg2mp4.mjs assets/fig-x.svg`로 같은 이름의 `.mp4`를 만들어 둔다. `make_pptx.py`가 PPTX에서 정지 그림을 이 영상으로 바꾸고, 슬라이드에 들어가면 자동 재생·반복하도록 설정한다.
- PowerPoint는 한글을 글자 단위로 줄바꿈하므로 두 줄 이상 문장은 HTML에서 `<br>`로 줄바꿈 위치를 고정한다.
- 글꼴은 PC에 설치된 Paperlogy 4 Regular / 8 ExtraBold만 쓴다(발표 PC에도 설치 필요, 아니면 PDF로 발표).
